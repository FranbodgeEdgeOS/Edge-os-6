# Edge OS 6

**A custom Android ROM project for the Samsung Galaxy S6 Edge (SM-G925F).**

Edge OS is a custom ROM project based on LineageOS, focused on bringing a personalized Android experience to the Galaxy S6 Edge.

## 🚀 Versions

| Version | Android | Status |
|---|---|---|
| **Edge OS 6.15** | Android 15 | ✅ Released |
| **Edge OS 6.16** | Android 16 | 🛠️ In Development |

### Edge OS 6.15

- Based on Android 15 and LineageOS.
- Released as a beta build.
- Confirmed working on the Samsung Galaxy S6 Edge SM-G925F.
- Flashable ZIP package for TWRP recovery.

**Download:** [Edge OS 6.15 — GitHub Releases](https://github.com/FranbodgeEdgeOS/Edge-os-6/releases/tag/S6_edge)

### Edge OS 6.16 — In Development

Edge OS 6.16 is currently under development.

Planned work includes:
- Updating the ROM base to LineageOS 23 (Android 16).
- Custom Edge OS branding and boot animation.
- System improvements and stability testing.
- Preparing a new flashable ZIP for TWRP.

**Note:** Edge OS 6.16 is not yet released. Features and compatibility may change during development.

## ⚠️ Disclaimer

Edge OS is provided "as is", without warranty.

Flashing a custom ROM can erase your data, cause boot problems, and permanently trip the Samsung Knox warranty bit. You are responsible for backing up your data and understanding the risks before installing.

Always verify device compatibility before flashing.
