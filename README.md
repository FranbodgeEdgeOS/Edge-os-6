## 📱 About

**Edge OS 6** is an unofficial Android project led by **FranbodgeEdgeOS**, aiming to bring Android 15 to the Samsung Galaxy S6 Edge.

The project is intended to use **LineageOS 22.1** as its base, with a focus on performance, customization, and extending the life of this classic device.

**This project is in beta development.** Features, stability, and compatibility are not guaranteed.

## 🎯 Target device

- **Device:** Samsung Galaxy S6 Edge
- **Model:** SM-G925F
- **Codename:** `zeroltexx`
- **Target Android version:** Android 15
- **Intended base:** LineageOS 22.1

> Support for other Galaxy S6 Edge variants has not been confirmed.
